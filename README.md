# 接龍

單一 HTML 檔的 Klondike 接龍網頁遊戲，不用安裝、不用建置，打開 `index.html` 就能玩。

## 功能

- 4 套牌面主題（貓咪、兔兔、熊熊、小雞）與 6 種桌面背景，可隨時切換
- 一次抽 1 張或 3 張
- 「保證有解」發牌：發牌前用解題器（DFS，在 Web Worker 中執行）確認牌局有解
- 提示會用解題器算出真正會通的下一步；走進死局時可一鍵退回到最近一個還有解的局面
- 點一下自動移牌、拖曳、復原（Ctrl+Z）、自動收牌、計時與步數
- 支援手機觸控

## 檔案

- `index.html`：遊戲本體（樣式、程式、解題器都在裡面）
- `solver.js`：解題器的獨立版本，可用 Node 測試（`require('./solver.js')()`）
